# -------------------------------------------------------
# WHY WAS THE BACKEND OFFLINE WHEN IDE / PC WAS CLOSED?
# -------------------------------------------------------
# Cloudflare Pages / Workers only hosts static HTML/JS frontend assets.
# Cloudflare cannot run Python FastAPI, ChromaDB, or SQLite.
# Previously, the backend was running on your local computer via a temporary
# tunnel (trycloudflare.com). Whenever you close your IDE or computer,
# that local backend process terminates, causing Cloudflare to show "Backend Offline".

# -------------------------------------------------------
# HOW TO KEEP BACKEND ONLINE 24/7 (ALWAYS ONLINE):
# -------------------------------------------------------
# Deploy the backend to Render.com (100% Free 24/7 Python Web Service):
# 1. Go to https://dashboard.render.com
# 2. Click "New +" -> "Blueprint" (or "Web Service")
# 3. Connect your repository: https://github.com/shanks-not-found/change-radar
# 4. Render will automatically read `render.yaml` from the repo:
#    - Root Directory: backend
#    - Build Command: pip install -r requirements.txt
#    - Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
# 5. Add your Environment Variable in Render:
#    - GROQ_API_KEY: (your Groq API key)
# 6. Click "Deploy". Render will give you a permanent 24/7 HTTPS URL, e.g.:
#    https://change-radar-backend.onrender.com
# 7. Open your Cloudflare site (change-radar.pages.dev), click the "Backend Offline"
#    pill in the top-right header, paste the Render URL, and click "Test & Save".
#    Or set VITE_API_URL in frontend/.env / wrangler.toml and redeploy!

# -------------------------------------------------------
# LOCAL DEVELOPMENT (Only when developing on your machine)
# -------------------------------------------------------
# Terminal 1 - Backend:
cd "d:\github\change radar\backend"
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 - Frontend:
cd "d:\github\change radar\frontend"
npm run dev

# -------------------------------------------------------
# TEMPORARY TUNNEL (For testing local PC backend through Cloudflare)
# Note: Only works while terminal & IDE are kept open!
# -------------------------------------------------------
npx --yes cloudflared tunnel --url http://localhost:8000

# -------------------------------------------------------
# BUILD & DEPLOY FRONTEND TO CLOUDFLARE
# -------------------------------------------------------
cd "d:\github\change radar\frontend"
npm run build

# Deploy to Cloudflare Pages (change-radar.pages.dev):
cd "d:\github\change radar"
npx wrangler pages deploy frontend/dist --project-name change-radar

# -------------------------------------------------------
# PUSH TO GITHUB (Syncs changes & updates Render backend)
# -------------------------------------------------------
git add .
